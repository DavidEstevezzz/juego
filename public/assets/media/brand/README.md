# Marca del estudio

Coloca aquí el logotipo oficial de Strange Creature Factory con este nombre
exacto, porque es la ruta que usa el hero:

    strange-creature-factory.png

Formato recomendado: PNG con fondo transparente (o SVG, cambiando entonces la
ruta en `content/site-content.ts` → `hero.studioLogo`). Ancho mínimo de 1200 px
para que se vea nítido en pantallas de alta densidad.

El logotipo se trata como activo gráfico y no se reconstruye con fuentes web,
según docs/VISUAL-DIRECTION.md.
